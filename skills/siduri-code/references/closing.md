# closing - closing a wave

**v1 - 25 Aug 2026.** Read when closing a wave. `CL` rules live in `SKILL.md`.

---

## Read the tree, never the report

Worker report is a claim. Every Done-when is planted at close, not read.

Spine lane reported green and was green - and reading the tree still found three
thing the report did not carry: the seam could not survive the fan-out it existed
for, a nav item shipped a 404, and the preview URL hardcoded one post's slug.
None was a failure of the lane. All three were invisible from inside it.

## The end-to-end line

Every wave close with a page opened and read by a person, quoted:

    HTTP 200, 3154 bytes, <h1>Hello, Siduri</h1>
    first paragraph: "I am documenting what it takes to ship..."
    grep -c "<script" → 0

Not a suite, not a pipeline. Five package, five session, one night, 1854 test
passed uncached, thirty-nine of forty mutation caught, CI green through nineteen
step, image pushed - and nothing served the page. Every package's Done-when named
its own file and every one was met honestly.

Read every lane's Done-when and ask which name the product. All naming a file
mean nobody test composition.

## Finding row

Where found, what break, **what it look like when it break**. The third column is
the one that make a row useful a week later, and it is the one that get dropped.

Row whose evidence a later action erase carry its date and that action.

## Decision row

Decision land a row carrying the lead's position, the reviewer's verdict **with
its scope**, and the operator's ruling. Agreement with no scope attached is what
turn into laundering three week later.
